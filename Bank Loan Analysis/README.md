Bank Loan Analysis & Risk Dashboard

📌 Project Overview
    This project features an interactive and dynamic Bank Loan Analysis Dashboard designed to monitor loan portfolio performance, assess financial default risks, and uncover actionable insights for data-backed lending decisions.
    The dashboard enables financial analysts and stakeholders to evaluate core lending metrics, track monthly trends, analyze geographical loan distribution, and differentiate between low-risk (Good) and high-risk (Bad) loan applications.

📊 Key Features & Functionalities
  1. High-Level Financial KPIs:
          Total Loan Applications: Tracks the overall volume of incoming loan applications.
          Total Funded Amount: Measures the total capital disbursed across all loan types.
          Total Amount Received: Monitors total cash inflow from loan repayments.
          Avg Interest Rate & DTI: Tracks average borrowing costs and borrower Debt-to-Income (DTI) ratios to evaluate borrower creditworthiness.
          
  2. Portfolio Health & Risk Segmentation:
          Good Loan vs. Bad Loan Breakdown: Differentiates healthy loans (Fully Paid / Current) from non-performing loans (Charged Off).
          Funded vs. Received Comparison: Evaluates capital recovery against original disbursements across different loan statuses.

  3. Geographical & Time-Series Analysis:
        Monthly Application Trends: Line chart depicting application volume trajectory throughout the year.
        Geographical Distribution: Interactive US Map displaying regional concentration of loan applications by state.
     
📁 Dashboard Structure
    Page 1 (Summary/Dashboard): Focuses on core KPIs, Good vs. Bad loan distribution, and repayment metrics.
    Page 2 (Overview/Details): Deep dives into temporal trends, geographical heat maps, loan purposes, and homeownership profiles.

🛠️ Tech Stack & Tools
    BI & Visualization: Power BI
    Data Processing & Analytics: DAX and Power Query
    Data Source: Excel, Financial lending dataset containing anonymized loan applicant records.
    Bancground & UI design: Microsoft PowerPoint
